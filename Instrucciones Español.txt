# 🤖 AI Stem Splitter by Oliver Tkach

### **Versión 2.0 (Unificada)** Un ReaScript profesional para **REAPER** que utiliza Inteligencia Artificial para separar audio en 6 pistas de alta fidelidad.

> **Nota:** Soy ante todo un **apasionado del audio**, no un desarrollador profesional. Esta herramienta nació de una necesidad en mi propio flujo de trabajo y fue construida con ayuda de IA. ¡La comparto para que otros productores puedan beneficiarse!

---

## 🛠️ Requisitos Obligatorios

*Configuración única para Windows*

1. **Python 3.10+ (El Motor)** * Descárgalo de [python.org](https://www.python.org/).
* ⚠️ **CRÍTICO:** **DEBES** marcar la casilla **"Add Python to PATH"** durante la instalación.
Si no te aparece en la instalación o no pudiste, probá con este video:
🤔💻👨‍💻¿Cómo agregar Python al Path de Windows? - https://www.youtube.com/watch?v=B08TNPt7a-M

2. **FFmpeg (El Traductor de Audio)** * Abre el **Símbolo del Sistema (CMD)** como Administrador y ejecuta:
`winget install Gyan.FFmpeg`
* *Reinicia REAPER después de esto.*


3. **Visual C++ Redistributable** * Necesario para el procesamiento matemático: [Descargar aquí](https://www.google.com/search?q=https://aka.ms/vs/17/release/vc_redist.x64.exe).
4. **Librerías Esenciales (Solución Manual)** * Si ves errores de "Dependencies Missing", ejecuta esto en el **CMD**:
`pip install demucs soundfile==0.12.1 librosa numpy scipy torchcodec`

## ✨ Novedades de la Versión 2.0

| Función | Descripción |
| --- | --- |
| **Perfiles de Calidad** | Elige entre **Fast**, **Balanced** o **High** (Velocidad vs. Fidelidad). |
| **Modo de 2 Pistas** | Extrae solo **Vocales** (Acapella) vs **Instrumental**. |
| **Precisión de Salida** | Soporte profesional para **32-bit float** o **24-bit int**. |
| **BPM y Color Auto** | Detecta el tempo, ajusta el grid de REAPER y colorea las pistas. |
| **Control de Hardware** | Usa **CUDA (NVIDIA)** o **MPS (Apple)** para procesar en segundos. |
| **Seguridad de Memoria** | **Segment Seconds** evita cierres en PCs con poca RAM. |

## 🚀 Modo de Uso

1. **Cargar:** En REAPER, ve a **Action List (?) > New Action > Load ReaScript...** y selecciona el archivo `.lua`.
2. **Seleccionar:** Haz clic en un ítem de audio en tu proyecto.
3. **Ejecutar:** Haz clic en **Run**, elige tu configuración en la interfaz y presiona **"Start Split"**.
4. **Esperar:** La primera vez descargará aprox. 2GB de modelos de IA. **No cierres la ventana.**
5. **Resultado:** Obtén 6 pistas organizadas, coloreadas y perfectamente alineadas.
